
# DecisionHub

A Collaborative Decision-Making & Community Polling Platform.

## Project Description
DecisionHub helps users create decision boards, compare options, participate in polls, and make informed decisions through community feedback.

## My Role: Backend Development

Responsible for developing backend functionality using Java and Spring Boot.

## Technology Stack
- Java
- Spring Boot
- Spring Security
- Spring Data JPA
- Hibernate
- JWT Authentication
- MySQL
